*𝗋𝐚𝐢𝗇 𝗀𝐚𝗍𝗁𝐞𝗋𝗌 𝖻𝐞𝗅𝐨𝗐 𝗍𝗁𝐞 𝗅𝐞𝗍𝗍𝐞𝗋𝗌; 𝗍𝗁𝐞 𝗇𝐮𝗆𝖻𝐞𝗋 𝐨𝖿 𝖽𝗋𝐨𝗉𝗌 𝗋𝐞𝗆𝐞𝗆𝖻𝐞𝗋𝗌 𝐚 𝖽𝐢𝗀𝐢𝗍.*

𝗁𝐢𝖽𝐞 𝐚 𝗆𝐞𝗌𝗌𝐚𝗀𝐞 𝐢𝗇 𝗍𝗁𝐞 𝗋𝐚𝐢𝗇 𝖻𝐞𝗇𝐞𝐚𝗍𝗁 𝐚 𝖼𝐚𝗋𝗋𝐢𝐞𝗋 𝗉𝐨𝐞𝗆. 𝗆𝐨𝐨𝗇 𝗍𝐞𝐚𝗋𝗌 𝖼𝐨𝐮𝗇𝗍𝗌 𝗍𝗁𝐞 𝗆𝐚𝗋𝗄𝗌: 𝗍𝗐𝐨 𝗍𝗁𝗋𝐨𝐮𝗀𝗁 𝗌𝐞𝗏𝐞𝗇 𝖽𝗋𝐨𝗉𝗌 𝖼𝐚𝗋𝗋𝗒 𝖻𝐚𝗌𝐞-𝗌𝐢𝗑 𝖽𝐢𝗀𝐢𝗍𝗌; 𝐚 𝗌𝐢𝗇𝗀𝗅𝐞 𝖽𝗋𝐨𝗉 𝐢𝗌 𝐚𝗍𝗆𝐨𝗌𝗉𝗁𝐞𝗋𝐞.

𝖼𝗁𝐨𝐨𝗌𝐞 **𝖼𝐨𝗆𝗉𝐚𝖼𝗍 𝐚𝗌𝖼𝐢𝐢** 𝖿𝐨𝗋 𝗍𝗁𝗋𝐞𝐞 𝖽𝐢𝗀𝐢𝗍𝗌 𝗉𝐞𝗋 𝖼𝗁𝐚𝗋𝐚𝖼𝗍𝐞𝗋, 𝐨𝗋 **𝐮𝗇𝐢𝖼𝐨𝖽𝐞 𝖻𝗒𝗍𝐞𝗌** 𝖿𝐨𝗋 𝖿𝐨𝐮𝗋 𝖽𝐢𝗀𝐢𝗍𝗌 𝗉𝐞𝗋 𝐮𝗍𝖿-8 𝖻𝗒𝗍𝐞. 𝗌𝗉𝗋𝐞𝐚𝖽 𝗍𝗁𝐞 𝗉𝐚𝗒𝗅𝐨𝐚𝖽 𝐚𝖼𝗋𝐨𝗌𝗌 𝗍𝗁𝐞 𝗐𝗁𝐨𝗅𝐞 𝗉𝐨𝐞𝗆 𝐨𝗋 𝗀𝐚𝗍𝗁𝐞𝗋 𝐢𝗍 𝐚𝗍 𝗍𝗁𝐞 𝖿𝗋𝐨𝗇𝗍. 𝖽𝐞𝖼𝐨𝖽𝐞 𝖻𝗒 𝖼𝐨𝐮𝗇𝗍𝐢𝗇𝗀 𝗍𝗁𝐞 𝗋𝐚𝐢𝗇.

𝐨𝗉𝐞𝗇 `index.html` 𝖿𝐨𝗋 𝗍𝗁𝐞 𝐨𝖿𝖿𝗅𝐢𝗇𝐞 𝗐𝐨𝗋𝗄𝗌𝗁𝐨𝗉. 𝗋𝐮𝗇 `python -m unittest -v` 𝖿𝐨𝗋 𝗍𝗁𝐞 𝗍𝐞𝗌𝗍𝗌 𝐨𝗋 `python moon_tears.py --help` 𝖿𝐨𝗋 𝗍𝗁𝐞 𝖼𝗅𝐢. 𝗇𝐨 𝖽𝐞𝗉𝐞𝗇𝖽𝐞𝗇𝖼𝐢𝐞𝗌, 𝐮𝗉𝗅𝐨𝐚𝖽𝗌 𝐨𝗋 𝗄𝐞𝗒𝗌.

𝗆𝐨𝐨𝗇 𝗍𝐞𝐚𝗋𝗌 𝐞𝗇𝖼𝐨𝖽𝐞𝗌 𝖻𝗒 𝗌𝗍𝐚𝖼𝗄 𝗁𝐞𝐢𝗀𝗁𝗍. 𝗓𝐚𝗅𝗀𝐨 𝐞𝗇𝖼𝐨𝖽𝐞𝗌 𝖻𝗒 𝗆𝐚𝗋𝗄 𝐢𝖽𝐞𝗇𝗍𝐢𝗍𝗒; 𝖽𝐢𝐚𝖼𝗋𝐢𝗍𝐢𝖼 𝖻𝗅𝐨𝐨𝗆 𝖼𝐨𝗆𝗉𝐨𝗌𝐞𝗌 𝗏𝐢𝗌𝐢𝖻𝗅𝐞 𝗅𝐞𝗍𝗍𝐞𝗋-𝐚𝗇𝖽-𝗆𝐚𝗋𝗄 𝗋𝐞𝖼𝐢𝗉𝐞𝗌. 𝐞𝐚𝖼𝗁 𝗁𝐚𝗌 𝐢𝗍𝗌 𝐨𝗐𝗇 𝗏𝐨𝐢𝖼𝐞.

𝗍𝗁𝐞 𝗍𝗐𝐨 𝗆𝐨𝖽𝐞𝗌 𝐚𝗇𝖽 𝗆𝐚𝗋𝗄 𝐨𝗋𝖽𝐞𝗋 𝖼𝐨𝗆𝐞 𝖿𝗋𝐨𝗆 𝗅𝐢𝗅𝗒'𝗌 𝐨𝗋𝐢𝗀𝐢𝗇𝐚𝗅 𝗐𝐨𝗋𝗄. `historical/` 𝗉𝗋𝐞𝗌𝐞𝗋𝗏𝐞𝗌 𝗍𝗁𝐞 𝗉𝗒𝗍𝗁𝐨𝗇, 𝗁𝗍𝗆𝗅, 𝖼𝐚𝗋𝗋𝐢𝐞𝗋 𝐚𝗇𝖽 𝗁𝐨𝗇𝐞𝗒𝗌𝐮𝖼𝗄𝗅𝐞 𝗌𝗉𝐞𝖼𝐢𝗆𝐞𝗇 𝖿𝗋𝐨𝗆 `moon_tears_cipher_bundle.zip` 𝖻𝗒𝗍𝐞 𝖿𝐨𝗋 𝖻𝗒𝗍𝐞. 𝗍𝗁𝐞 𝖼𝐮𝗋𝗋𝐞𝗇𝗍 𝐚𝖽𝐚𝗉𝗍𝐞𝗋𝗌 𝗏𝐚𝗅𝐢𝖽𝐚𝗍𝐞 𝖽𝐞𝖼𝐨𝖽𝐞𝖽 𝗏𝐚𝗅𝐮𝐞𝗌, 𝗌𝗍𝐚𝖼𝗄 𝗁𝐞𝐢𝗀𝗁𝗍, 𝐮𝗍𝖿-8 𝐚𝗇𝖽 𝗋𝐞𝗌𝐞𝗋𝗏𝐞𝖽 𝖼𝐚𝗋𝗋𝐢𝐞𝗋 𝗆𝐚𝗋𝗄𝗌 𝗐𝗁𝐢𝗅𝐞 𝗉𝗋𝐞𝗌𝐞𝗋𝗏𝐢𝗇𝗀 𝗍𝗁𝐞 𝐨𝗋𝐢𝗀𝐢𝗇𝐚𝗅 𝗐𝐢𝗋𝐞 𝖿𝐨𝗋𝗆𝐚𝗍.
